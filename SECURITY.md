# Security

Do not post passwords, DNS keys, connection URLs, master keys, database files or certificates with private keys in public issues. Redact screenshots before publishing.

Removing a leaked credential from history does not revoke it. Rotate confirmed exposed credentials and tell affected operators what must be reconfigured. Follow least privilege for the web process and privileged DNS/proxy agent.

Report implementation vulnerabilities privately to the repository maintainer through GitHub's private reporting facilities when available. Describe affected versions and reproduction without production secrets.
