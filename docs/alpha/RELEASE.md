# 0.1.0-alpha.1

Первая развёрнутая альфа-версия Зелёнка DNS.

- Личные профили DoT/DoH и профиль Apple.
- До трёх активированных сетей на пользователя на семь дней.
- Выборочное HTTPS-проксирование через Финляндию.
- AdGuard DNS Filter + HaGeZi Multi PRO.
- Управление по SSH, отдельный контейнер и резервная копия с откатом.
- 30 параллельных профилей: 300 DNS-запросов без ошибок, 30 соединений через прокси.
- Владелец подтвердил работоспособность подключения.

Известные ограничения и фактические проверки: docs/VALIDATION.md. Управление: docs/OPERATIONS.md.

Приватные ссылки подключения, ключи, сертификаты и база пользователей в исходники не включены.
