# Проверки 0.1.0-alpha.1

Дата: 31 октября 2026 года, Europe/Moscow. Развёртывание: исходная финская VPS, Ubuntu 26.04.1, AdGuard Home v0.107.79, HAProxy 3.2.9, nginx 1.28.3.

## Подтверждено

- 6 локальных тестов: секреты, отключённые пользователи, отклонение непубличных адресов, лимит трёх сетей и истечение срока, одновременные активации, границы доменов, профиль Apple.
- Доверенный сертификат для основного имени и профиля владельца. DoH и DoT отвечают с проверкой доверия системным хранилищем сертификатов.
- Пробное автоматическое продление Certbot через ACME staging завершилось успешно.
- Обычные домены получают исходные ответы; chatgpt.com получает адрес VPS. Для перенаправляемых доменов AAAA, HTTPS и SVCB возвращают пустой NOERROR. IPv6 обычных доменов сохраняется.
- doubleclick.net блокируется ответом 0.0.0.0.
- Подмена X-Real-IP/X-Forwarded-For при активации не меняет фактический адрес клиента.
- Неизвестные DoH-профили и административные HTTP-пути отклоняются. Неизвестное имя DoT отклоняется.
- example.com и evilchatgpt.com не принимаются в качестве произвольных направлений прокси.
- Изолированное сетевое пространство на VPS: DNS по UDP/TCP не отвечает до разрешения IP, отвечает после разрешения и перестаёт отвечать после истечения kernel timeout. Тестовые интерфейсы и пространство удалены.
- Диагностический HTTPS-запрос chatgpt.com/cdn-cgi/trace через прокси показал выходной адрес VPS и loc=FI; сертификат исходного сервиса проверялся обычным TLS-клиентом.
- Реальный временный профиль: до отключения портал и DoH доступны; после отключения оба возвращают 403. Профиль владельца продолжает работать. Временный профиль удалён.
- Четыре прежних backend HAProxy совпадают с резервной копией; исходный фильтрующий DoH отвечает успешно.
- Владелец подтвердил работу на своём устройстве и принял результат как альфа-версию.

## Нагрузка

30 активных тестовых профилей, 30 параллельных клиентов, 10 секунд:

| Показатель | Результат |
|---|---:|
| Успешные DoH-запросы | 300 |
| Ошибки DNS | 0 |
| Успешные соединения через прокси | 30 |
| Медиана полного времени DoH из среды проверки | 162.0 мс |
| 95-й перцентиль | 421.1 мс |
| Память нового AdGuard во время проверки | около 95.5 МиБ из 512 МиБ |
| CPU нового AdGuard в контрольном замере | 1.61% |

Действующие VPN оставались запущены. Их пропускная способность одновременно с видео-нагрузкой не измерялась. Временные профили удалены; сертификаты для них не выпускались.

## Проверки страниц через прокси

HTTP-ответы получены с проверкой исходных TLS-сертификатов: Gemini 200, Google AI Studio 302, Spotify 200, YouTube 200, Discord 200. Claude вернул 403 с Cloudflare-проверкой. Это подтверждает сетевую маршрутизацию, но само по себе не проверяет вход в аккаунт, ответ модели или воспроизведение контента.

Обычный порт 53 из среды выполнения проверок был недоступен, а UDP-сокеты ограничивались средой. Поэтому отдельно проверены оба протокола и firewall через изолированное сетевое пространство на самой VPS; работа обычного DNS у конкретного провайдера требует клиентской проверки.
